## ⚙️ 6. Installation/Setup

### Prerequisites

* Python 3 installed on your computer
* Git installed on your computer

### Step 1: Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/shivam2007jha123/python-practice.git
```

### Step 2: Navigate to the Project Directory

```bash
cd python-practice
```

### Step 3: Verify Python Installation

```bash
python --version
```

On Windows, you can also use:

```bash
py --version
```

## ▶️ 7. How to Run the Project

1. Open the repository folder in Visual Studio Code or another code editor.
2. Select the Python program you want to execute.
3. Open a terminal in the project directory.
4. Run the program using:

```bash
python filename.py
```

Replace `filename.py` with the actual name of your Python file.

On Windows, you can alternatively use:

```bash
py filename.py
```

**Note:** Run the individual Python file you want to execute. The repository contains practice programs that may run independently.
